The wrapper reuses a baseline model only when discovered initialization is exactly equal and all lead bytes, provenance, and schedule are verified; otherwise it downloads and decodes the new native cycle. Chart signatures include product/domain/valid time/exact accumulation window and ordered model initialization, lead and numerical hash; unchanged signatures are reuse candidates only under an unchanged renderer, not actual pixel comparison or measured render time.
