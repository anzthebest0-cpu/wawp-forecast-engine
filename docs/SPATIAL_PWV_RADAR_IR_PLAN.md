# Additional spatial diagnostics — PWV, reflectivity and IR

2026-11-25. Source documentation inventory, not a production integration.

- Native PWV: GFS PWAT (kg m^-2, numerically mm), ECMWF IFS tcwv (not tcw), ICON tqv. AIFS actual tcwv coverage must be confirmed; do not approximate total PWV using a few pressure levels. Compare matched valid time, native terrain and climatology. No universal warning threshold.
- GFS native REFC: official NCEP inventory https://www.nco.ncep.noaa.gov/pmb/products/gfs/gfs.t00z.pgrb2.0p25.f003.shtml . Test bounded NOMADS regional retrieval, verify GRIB code, level, step type, valid time, dBZ units, bitmap and missing/no-echo conventions before plotting. Coarse model composite reflectivity is not observed radar or a tactical CB/airport warning. WRF simulated composite reflectivity is a future independent experiment.
- ECMWF simulated IR official chart: https://www.ecmwf.int/en/forecasts/datasets/simulated-images-infrared ; linked Open Charts https://charts.ecmwf.int/products/medium-simulated-ir (automated web access denied during research). Do not bypass protection. Confirm regional view, freshness, rights and access via documented interfaces. RTTOV sensor/channel simulation requires model atmospheric/cloud profiles and appropriate coefficients. BMKG INA-NWP 9/3 km study https://doi.org/10.1002/qj.70332 is relevant to future station WRF work.
- GFS TOA ULWRF and ECMWF ttr are broadband outgoing longwave radiation diagnostics, not Himawari channel-specific BT. Respect averaging intervals, accumulated energy vs flux, and sign conventions. Do not label OLR-derived equivalent emission temperature as satellite IR.
- Initial ECMWF inventory run 45599975062: both IFS grids all eight baseline fields present at H+0/6/12; AIFS lacked native RH at 700/850 but co-located q and T exist. IFS 0.25 baseline transfer approx 4.35 MB per lead vs 20.2–20.8 MB for 0.1. No GRIB field retrieval or charts for ECMWF yet. IFS two grids are not independent forecasts.
- Expanded ECMWF metadata-only inventory now includes tcwv, tcw, ttr, cloud water/ice/rain, total cloud cover and mucape. Availability remains to be verified by CI. Next actual pilot: GFS PWAT/REFC, then matched-cycle IFS PWV; separate validated observed radar and observed Himawari B13 from any model diagnostics. No production changes.
