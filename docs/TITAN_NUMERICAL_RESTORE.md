# Numerical recovery / restore proof
The Drive archive has not completed a five-model generation because of repeated provider rate limits. Do not represent incomplete packs as a restorable generation. This workflow separates a real-source local restore rehearsal from a true read-only remote restore. The default push rehearsal repacks the independently validated main run 45924430403 using the original deterministic pack contract, restores the cache, checks exact file names, hashes, native lead schedules, array shape/field membership and original NPZ byte identity, and rejects an incorrect ZIP digest. No numerical data or restored cache is published; only the counts-only report is retained. Remote mode requires a committed generation ID and independent approved catalog SHA-256. It validates exact live Drive object IDs, ZIP size/hash, manifest and numerical data. Remote mode is disabled by default and no archive is assumed complete. It verifies recovery in a disposable directory; it does not switch the production baseline or regenerate charts. To recover production after artifact expiry, a separate controlled baseline migration must use the validated restored cache and separately verified chart generation.
