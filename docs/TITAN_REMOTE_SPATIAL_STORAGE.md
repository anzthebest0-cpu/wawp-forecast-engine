# Remote spatial storage experiment
This branch uses real frozen numerical artifacts (81 leads, five model collections) and two verified 1,563-chart site revisions. It is deliberately separate from production. A run-specific private Drive validation prefix holds deterministic stored ZIPs: one numeric pack per model collection, one chart pack per render collection, one metadata pack per revision, immutable generation manifests, and sequential commit markers published only after full verification. Each pack is identified by SHA-256; each member has its original hash. Remote exact-ID readback verifies every pack and its contents. The replay of the same refined revision tests idempotence, incomplete candidate rejection, and chart retention; it is not a new weather cycle. Only the superseded chart pack in this fixture prefix may be moved to Trash after verifying current and previous, with all numerical and metadata objects preserved. No permanent removal; no production checkpoint changes, deployment, or public access. Retained preview data are frozen and must not be presented as current forecasts. A private archive is not a public serving backend. Independent native-cycle deduplication, freshness and operational writer/reader recovery, quota policy and public preview are later stages. The rehearsal may transfer over 1 GB of readbacks; Drive throttling or expired Actions input artifacts may stop it. The initial archive uses entire model-collection packs, so overlapping lead subsets cannot deduplicate across distinct packs; measure this before choosing the operational granularity.
