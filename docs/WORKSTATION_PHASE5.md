# Phase 5 — historical presentation and AWOSnet reuse

Original Android implementation: branch wawp-wind-watch, commit 3b8c81209dd9cb1be753253758bbdee69f18b770, android/wawp-wind-watch/app/src/main/java/com/wawp/windwatch/AwosClient.java and WindMonitorService.java. Direct HTTP, timestamp cache-busting, 5s connect/read timeout, attribute value extraction, case-insensitive wind tags, UTC date formats dd/MM/yyyy or yyyy-MM-dd with HH:mm[:ss], 10s/5s polling, five-minute freshness in current service (README says three). Android cleartext exception is host-specific and cannot transfer to HTTPS Pages. Prior client did not enforce airport equality in isFresh, clamps future age to zero, strips arbitrary nonnumeric characters and does not validate explicit units; do not copy those weaknesses.

The probe now uses cache busting and no-cache. Offline adapter scripts/normalize_awosnet_xml.py reuses known wind-only mapping, strictly checks WAWP, UTC date, units where present, duplicate fields, numeric ranges, future timestamps and XML declarations. Requires explicit source semantics confirmation; actual XML has not been re-fetched. Gust averaging interval and true-north reference still need station confirmation. Temperature, dewpoint and QNH deliberately null because original Android parser did not establish these. No automatic polling or public upload. Use an authorized locally captured XML file and an approved output directory outside repo:
python scripts/normalize_awosnet_xml.py <private-xml-file> --output <private-output.json> --confirmed-source-semantics
Then manually import output into local dashboard. Do not use the flag until UTC, units, 2-minute wind and directional reference are confirmed.

Historical scorecard displays existing metrics without recalculation or ranking; paired N not exported. DM text no longer equates p<0.05 with better weighted forecast. Legacy diurnal bias plot withheld because exporter fills missing hours and circular bias with zero. Climatology means and peak exclude missing values; wind direction table avoids incorrectly substituting wet-only distribution for all conditions. Fog proxy axes separated. Labels clarify historical means vs actual events. No new observations, verification scores, forecast algorithms, archives or safety gates modified. Browser testing and actual source validation remain required.
