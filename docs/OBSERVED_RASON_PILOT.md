# Observed radiosonde CAPE pilot
NOAA NCEI IGRA v2.2 YTD station data, one-time bounded archive retrieval, not live sounding feed. Official list https://www.ncei.noaa.gov/pub/data/igra/igra2-station-list.txt and directory https://www.ncei.noaa.gov/pub/data/igra/data/data-y2d/ list 2026 files for 96935, 97180, 97230, 97372, 97502. Actual shared-cycle coverage remains unverified. Format https://www.ncei.noaa.gov/pub/data/igra/data/igra2-data-format.txt . Use reported surface, measured T and dewpoint depression, pressure monotonicity and duplicate checks; withhold insufficient profiles and positive CAPE with no resolved EL. MetPy parcel diagnostics distinct: SBCAPE/SBCIN, 100 hPa MLCAPE/MLCIN, 300 hPa MUCAPE/MUCIN. Mixed-layer EL check is preliminary and must be reviewed for exact consistency with MetPy's mixed-layer profile. SI, KI and first freezing crossing from observed profile. No interpolation or WAWP observed CAPE without local sounding. Plot station point maps and Skew-T. Select latest shared 00/12 UTC cycle no later than 25 Nov 00Z within previous five days, show actual time; no stale data as live, missing != zero. Daily archive update may lag. Authorized BMKG upper-air feed needed for reliable same-day Sulawesi coverage. Raw ZIPs in memory only, short-lived figures and manifest; no production changes. Model LI/SI/freezing pilot is separate and still pending.
