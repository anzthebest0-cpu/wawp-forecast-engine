# Stateless on-demand AWOSnet proxy

The dashboard has no configured proxy by default. No scheduled jobs, KV, D1, R2, raw XML archive, or database changes. Browser requests immediately when visible, then 60 seconds after each completed request; aborts requests and timers when hidden or page closes, immediately refreshes on return; manual refresh and pause available. Browser memory only. Manual file import pauses polling. One request in flight per page. Independent source clock and receipt time checked; failed request clears values. Forecast engine unaffected.

Cloudflare Worker candidate: fixed HTTP AWOSnet upstream, bounded XML, strict alias/units/station/freshness checks, normalized allowlist only, no response caching or observation logging, no redirects. HTTP upstream is unauthenticated; HTTPS browser leg does not authenticate source. Cloudflare reachability untested. CORS restricts browser reading, not authorization; anyone can spoof Origin, so do not enable unless public redistribution is expressly permitted. Use authenticated private deployment instead if restricted. Use provider rate limiting if public access is enabled. No API secrets embedded.

Deployment requires an authorized Cloudflare account, current Wrangler CLI, and confirmation of UTC display clock, true wind direction and public distribution rights. From services/awos-proxy install dependencies with npm install, run npm test, then npx wrangler deploy. Default flags false; deployment disabled even if reachable. Set confirmed flags only after review. Set ALLOWED_ORIGIN to actual dashboard origin, then redeploy. Validate HTTP upstream from Worker and ensure 200 normalized snapshot or explicit 502/503; verify no persistent logging or cache. Set docs/index.html meta titan-awos-proxy content to actual HTTPS endpoint ending /awos, after authorized deployment. No invented URL. Run browser checks and existing gated Pages publication separately. No token shared in chat or repo.

Tests use synthetic XML; no raw observation payload committed. Cloudflare free tier request limit subject to current terms. Polling may be throttled by browsers; not guaranteed aviation warning monitoring. Public origin restriction is not access control. A closed browser makes no new requests from that browser, but other viewers or clients may still request the endpoint.
